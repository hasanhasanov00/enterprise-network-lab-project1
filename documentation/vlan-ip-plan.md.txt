# VLAN and IP Addressing Plan

The network uses four VLANs to separate different departments and servers.

## VLAN Configuration

| VLAN ID | Name | Network | Gateway |
|---|---|---|---|
| 10 | HR | 192.168.10.0/24 | 192.168.10.1 |
| 20 | IT | 192.168.20.0/24 | 192.168.20.1 |
| 30 | SALES | 192.168.30.0/24 | 192.168.30.1 |
| 40 | SERVERS | 192.168.40.0/24 | 192.168.40.1 |

## Server IP Addresses

| Server | IP Address |
|---|---|
| DNS Server | 192.168.40.10 |
| Web Server | 192.168.40.20 |
| DHCP Server | 192.168.40.30 |

## DHCP Configuration

DHCP is configured to assign IP addresses automatically to HR, IT and SALES clients.

The DHCP server is located in VLAN 40. DHCP relay is configured on the router using the ip helper-address command.
